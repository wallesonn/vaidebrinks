# Próximos passos

Este documento registra o que ainda pode evoluir a partir do estágio atual.

## Possíveis melhorias futuras

- adicionar backend real para reservas;
- integrar autenticação de usuários;
- conectar estoque e disponibilidade a um calendário real;
- substituir o pagamento simulado por um gateway verdadeiro;
- criar painel administrativo para fornecedores;
- adicionar notificações por e-mail ou WhatsApp;
- criar testes automatizados para fluxos críticos.

## Áreas com maior impacto

- persistência de dados em banco;
- controle de disponibilidade em tempo real;
- experiência de checkout;
- gestão operacional das reservas.

## Situação atual

Nada disso é necessário para o funcionamento do protótipo atual. A versão presente já entrega uma experiência completa de frontend com dados simulados.

# Documentação do Vai de Brinks

Esta pasta reúne a documentação atual da plataforma **Vai de Brinks**, um protótipo frontend de reservas para brinquedos de festa infantil.

## Escopo atual

- Frontend completo com **Next.js 14**, **React 18**, **TypeScript** e **TailwindCSS**.
- Fluxo de reservas com telas de descoberta, detalhes, reserva, pagamento simulado, confirmação e gestão de reservas.
- Estado local com persistência em `localStorage`.
- Interface e conteúdo em **português do Brasil**.
- Catálogo, fornecedores, avaliações e reservas simulados com dados mockados.

## Observações importantes

- O projeto **não possui backend**.
- Não há integração com gateway de pagamento real.
- A experiência de pagamento, confirmação e cancelamento é simulada no frontend.
- O nome público da plataforma é **Vai de Brinks**.

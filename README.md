# Vai de Brinks

O **Vai de Brinks** é um SaaS frontend para aluguel e reserva de brinquedos de festa infantil.

## Stack atual

- Next.js 14
- React 18
- TypeScript
- TailwindCSS
- Docker / Docker Compose
- Traefik na VPS
- Postgres e Redis preparados na stack
